# Getting Started

## Requirements

Python 3. There are no runtime dependencies.

## Setup

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/024-mail-merge.git
cd 024-mail-merge
```

## Run

```bash
python main.py
```

## Tests

```bash
python -m py_compile main.py
```
